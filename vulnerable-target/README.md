# Уязвимое приложение-мишень

Минимальное приложение Next.js App Router, намеренно зафиксированное на **уязвимых**
версиях для демонстрации семейства React2Shell.

- **Next.js:** 15.0.4
- **React / React-DOM:** 19.0.0
- **react-server-dom-webpack:** 19.0.2 (уязвимый десериализатор)

## Что внутри

- `app/actions.ts` — `leakyAction`, серверный экшен (`'use server'`) — цель для 55183/55182.
- `app/client.tsx` — клиентский компонент, который дёргает экшен.
- `app/page.tsx` — страница, прокидывающая экшен в клиент.

## Запуск

```bash
npm install
npm run dev     # http://localhost:3000
```

Эксплойты из [`../../exploits`](../../exploits) стреляют по `localhost:3000`.

> ⚠️ Приложение уязвимо by design. Не деплоить. Только локально, для демонстрации.
